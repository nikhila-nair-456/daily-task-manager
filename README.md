# TaskFlow – Daily Task Manager

ReactJS Individual Self-Learning Assignment.

## Problem Statement
No. 12 – Daily Task Manager

Create a to-do application with add, edit, delete, completion status, and filtering.

## Features
- Dashboard with task statistics
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter by status and priority
- Form validation
- LocalStorage persistence
- Responsive design
- Three functional views: Dashboard, My Tasks, Add/Edit Task

## Technologies
- ReactJS
- JavaScript ES6
- HTML5
- CSS3
- Vite

## How to Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.
